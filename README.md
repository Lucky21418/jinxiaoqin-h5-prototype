# 金小勤 · 职工端 H5 可点击原型

金牛区机关事务管理局一站式服务平台（拟议）职工端演示。

## 本地运行

```bash
npm install
npm run build
npx vite preview --host 0.0.0.0 --port 5173
```

打开 http://127.0.0.1:5173/

## 公网演示

https://lucky21418.github.io/jinxiaoqin-h5-prototype/

- 仅职工端；演示身份 + localStorage 持久化
